# JJAK 프로필 등록 페이지

상담을 신청한 베트남 고객이 상세 프로필과 사진 5장을 제출하는 페이지입니다.
Google Apps Script 웹 앱 하나로 동작하며, 별도 서버·비밀 키가 필요 없습니다.

```
고객 휴대폰 ──(웹 앱 URL)──▶ Apps Script (소유자 권한으로 실행)
                                ├─ Google Sheets  「프로필 접수」에 한 행 기록
                                └─ Google Drive   「JJAK 프로필 사진/접수ID 이름/」에 사진 5장
```

| 파일 | 내용 |
| --- | --- |
| `apps-script/Index.html` | 고객 화면 (디자인은 `JJAK_profile_form.html` 그대로, 스크립트만 교체) |
| `apps-script/Code.gs` | 서버 코드: 검증, 시트·드라이브 저장, 중복 확인, 관리 메뉴 |
| `apps-script/appsscript.json` | clasp 로 배포할 때 쓰는 설정 (수동 배포 시 불필요) |
| `test/` | 로컬 테스트 (Google 서비스 모형 + 모바일 브라우저 테스트) |

---

## 1. 최초 배포 (약 10분, JJAK 운영용 Google 계정으로 진행)

1. Google Sheets 에서 새 스프레드시트를 만들고 이름을 `JJAK 프로필 접수` 로 정합니다.
2. **확장 프로그램 → Apps Script** 를 엽니다.
3. `Code.gs` 의 내용을 모두 지우고 이 저장소의 `apps-script/Code.gs` 를 붙여 넣습니다.
4. 왼쪽 **파일 +  → HTML** 을 눌러 이름을 `Index` 로 만들고, `apps-script/Index.html` 전체를 붙여 넣은 뒤 저장합니다.
5. 스프레드시트 탭으로 돌아가 새로고침하면 상단에 **JJAK 관리** 메뉴가 생깁니다.
   **JJAK 관리 → ① 초기 설정 실행** 을 누르고 권한 요청을 승인합니다.
   (시트 3개, 비공개 사진 폴더, 초대 코드가 만들어집니다.)
6. Apps Script 화면에서 **배포 → 새 배포 → 유형: 웹 앱**
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자**
   → 배포 후 표시되는 `…/exec` 주소를 복사합니다.
7. **JJAK 관리 → 고객용 링크 · 초대 코드 보기** 에서 초대 코드를 확인하고,
   고객에게는 `…/exec?k=초대코드` 형태의 주소를 Messenger / Zalo 로 보냅니다.
8. `담당자` 시트에 담당자의 Google 계정 이메일과 권한을 적고 **JJAK 관리 → ② 담당자 권한 적용** 을 실행합니다.

### 코드를 수정한 뒤 다시 배포할 때

Apps Script 에서 **배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포**.
이렇게 하면 고객용 주소가 바뀌지 않습니다. ("새 배포"를 누르면 주소가 바뀝니다.)

## 2. 운영 담당자 사용 안내

### 시트 구성

- **프로필 접수** — 고객 1명 = 1행. 최신 접수가 맨 아래에 추가됩니다.
  - `진행상태`: 드롭다운으로 직접 변경합니다. (`신규 접수 → 검토 중 → 상담 진행 → 완료 / 보류 / 삭제 요청`)
    `사진 업로드 중` 으로 남아 있는 행은 고객이 사진 전송을 끝내지 못한 접수입니다 → 고객에게 다시 제출을 안내하세요.
  - `중복 여부`: 같은 전화번호/Zalo, 또는 같은 이름+생년월일의 기존 접수가 있으면 그 접수ID가 표시됩니다(분홍색).
    기존 행은 덮어쓰지 않으므로 두 행을 비교한 뒤 필요 없는 쪽을 삭제하세요.
  - `사진 폴더`: 클릭하면 해당 고객의 Drive 폴더가 열립니다. 권한이 있는 계정으로 로그인해야 보입니다.
  - `담당자 메모`: 자유롭게 사용합니다.
  - 그 외 고객 입력 열과 `접수ID`, 숨겨진 `폴더ID` 열은 수정하지 마세요. 열 순서를 바꾸거나 열을 삭제하면 안 됩니다.
- **담당자** — 접근 권한 목록
  | 권한 | 시트 | 사진 폴더 |
  | --- | --- | --- |
  | 관리자 | 편집 | 편집 |
  | 상담원 | 편집 (상태·메모 입력) | 보기만 |
  | 열람 | 보기만 | 보기만 |

  이메일을 추가·삭제·변경한 뒤 **② 담당자 권한 적용** 을 눌러야 반영됩니다. 목록에 없는 계정은 접근 권한이 제거됩니다.
  시트와 폴더는 "링크가 있는 모든 사용자" 공유를 사용하지 않습니다. 공유 버튼으로 직접 추가하지 말고 이 시트로만 관리하세요.
- **삭제기록** — 언제, 누가, 어떤 접수ID를, 왜 삭제했는지만 남습니다(개인정보 없음).

### 고객이 삭제를 요청했을 때

`프로필 접수` 시트에서 해당 행을 선택 → **JJAK 관리 → 선택한 고객 삭제 (사진 포함)** → 사유 입력.
행이 삭제되고 사진 폴더는 휴지통으로 이동합니다(30일 후 완전 삭제. 즉시 지우려면 Drive 휴지통을 비우세요).

### 보관기한

접수 시 `보관 만료일`(접수일 + 12개월)이 기록됩니다.
월 1회 **JJAK 관리 → 보관기한 지난 고객 일괄 삭제** 를 실행하세요.
기간을 바꾸려면 `Code.gs` 의 `RETENTION_MONTHS` 와 `Index.html` 안내문의 "12 tháng" 을 함께 수정합니다.

### 링크가 외부에 퍼졌을 때

**JJAK 관리 → 초대 코드 새로 만들기** → 기존 링크는 즉시 무효가 되고 새 링크가 표시됩니다.

## 3. 보안 · 개인정보 처리 요약

- 고객 브라우저에는 Google 인증 정보가 전혀 없습니다. 저장은 모두 서버(Apps Script)가 소유자 권한으로 수행하며, 고객은 시트·드라이브 주소조차 받지 않습니다.
- 서버에서 다시 검증: 필수값, 만 18세 이상, 전화번호 형식, 선택지 값, 동의 2건(개인정보 수집·이용 / 한국 이전), 사진은 JPEG 5장·장당 3MB 이하.
- 사진은 브라우저에서 긴 변 1500px JPEG 로 다시 그려 전송합니다(원본의 위치정보 등 EXIF 가 제거됩니다).
- 무단·반복 제출 방지: 초대 코드(`?k=`), 숨김 입력란(봇 차단), 같은 번호 6시간 5회, 전체 10분 40건·하루 300건, 접수 1건당 업로드 30회 제한. 값은 `Code.gs` 의 `CFG.RATE`.
- 모든 값은 텍스트로 저장되어 스프레드시트 수식이 실행되지 않습니다.
- 동의 시각과 동의문 버전(`CONSENT_VERSION`)이 행마다 기록됩니다.
- 관리 기능은 스프레드시트 메뉴에서만 실행됩니다(웹 페이지에서는 호출 불가).

## 4. 테스트

```bash
node test/server.test.js
```

```bash
node test/e2e.js
```

두 테스트는 `Code.gs` 를 그대로 실행하지만 Google Sheets/Drive 는 **모형(mock)** 입니다.
실제 Google 계정에 배포한 뒤 아래 항목을 반드시 직접 확인하세요.

- [ ] 휴대폰(Messenger/Zalo 내장 브라우저 포함)에서 링크 열기 → 작성 → 사진 5장 → 동의 → 제출
- [ ] 시트에 행이 생기고 `진행상태` 가 `신규 접수`, 전화번호 앞자리 0 유지
- [ ] `사진 폴더` 링크 클릭 → 사진 5장 확인
- [ ] 권한 없는 계정/시크릿 창으로 시트·폴더 링크를 열면 "액세스 권한 필요"가 나오는지
- [ ] 관리자 / 상담원 / 열람 계정별로 열람·편집 범위가 표대로인지
- [ ] 같은 번호로 다시 제출 → 새 행 + `중복 여부` 표시
- [ ] 제출 중 비행기 모드 → 오류 메시지 → 다시 제출 시 정상 완료
- [ ] `?k=` 없이 접속하면 안내 문구만 나오는지

## 5. 다른 주소(자체 도메인)에서 폼을 띄우고 싶을 때 (선택)

`Index.html` 을 그대로 정적 호스팅에 올리고, 파일 안의 `var ENDPOINT = '';` 에 웹 앱 `/exec` 주소를 넣으면
같은 서버 코드(`doPost`)로 저장됩니다. Apps Script 주소 상단에 표시되는 Google 안내 배너를 없애고 싶을 때 사용합니다.
